# CERISE 🌐📡

O **repositório** possui arquivos destinados à minha pesquisa, com o objetivo de explorar como podemos **simular e analisar a propagação de sinais sem fio** em cenários urbanos.  
A proposta é unir ferramentas de simulação, como o **Sionna**, com técnicas de **aprendizado de máquina**, para compreender melhor a cobertura de sinal e propor formas de modelagem mais eficientes.

---

## ✨ O que este projeto busca
- Criar um **cenário simulado** de transmissão e recepção de sinal.
- Organizar os dados em **mapas de cobertura** que mostrem a intensidade do sinal em diferentes pontos.
- Experimentar modelos de **rede neural tradicional (MLP)** e de **rede neural informada pela física (PINN)**, avaliando como cada um se sai na tarefa de prever o comportamento do canal.

---

## 📂 O que você encontra aqui
- **Notebooks** com os experimentos e primeiros resultados.  
- **Dataset** com as posições dos receptores e a potência recebida.  
- **Arquivos de cenário** (meshes) usados para as simulações.  
- **Apresentações didáticas** que resume o caminho do projeto, do simulador até os modelos de IA.

---

## 💡 Em resumo
Este repositório é um espaço em construção, que reúne desde os dados brutos até as primeiras análises.  
O foco principal não é apenas ter um resultado final, mas **documentar o processo**, compartilhar aprendizados e abrir espaço para que outras pessoas também possam acompanhar.
